    Getting Started with Zenodo¶

    Overview

    This is the Getting Started page, part of Zenodo → Other Tools in the A-LIFE RDM collection.

    This document covers the first steps for using Zenodo:

    • Pre-Requirements — Sign up
    • Login
    • Upload Data
    • Best Practices for a good data file upload

    Supporting materials: GEMs, FAQs
    Authors: Irene Martorelli, Brett Olivier — Last modification: 2026-02-19 — Version: 0.6.0

    1. Pre-Requirements — Sign up¶

    Already have a Zenodo account?

    If you already have an account, skip to 2. Login.

    1a. Register¶

    To use Zenodo, you need a Zenodo account. Register here using your email address.

    Use a personal email address

    It is recommended to register with a personal email address rather than your institutional one — you may change institutions and lose access to your institutional account.

    1b. Link your Accounts¶

    You can connect other accounts to your Zenodo account by selecting Settings → Linked accounts from the dropdown beside your email address. Available options are ORCID, GitHub, and OpenAIRE.

    Connecting accounts to Zenodo

    Recommendation

    It is highly recommended to link your ORCID. Once linked, you can use it to log in and your author information will be auto-populated in new records.

    2. Login¶

    Log in at https://zenodo.org using your email, ORCID, or GitHub credentials (if linked). After login, select New Upload to start a new dataset record.

    3. Upload Data¶

    The New Upload option creates a new draft record. You will then see the Upload your files option — drag and drop files directly into the upload box, or use the file browser.

    Initiating a New Upload in Zenodo

    Uploading data files in the new record

    You can fill in metadata before uploading

    There is no required order — you can complete the metadata fields before uploading your files. Your record stays as a Draft until you decide to publish.

    Always include a README

    Include a README file as part of your dataset. See the Essentials — README section for templates and guidance.

    4. Best Practices for a good data file upload¶

    1. Check the number of files and size

    • Maximum 100 files per dataset record.
    • Maximum 50 GB per dataset.
    • For larger uploads, see How to request a quota increase.

    2. Package files in a ZIP archive

    • When uploading more than 20 files, it is recommended to ZIP your folder first.

    3. Check file names and formats

    • Remove hidden files (e.g. .DS_Store, __MACOSX) from ZIP archives before uploading.

    4. Include your README file

    • Include a README that describes the content of your uploaded files.
    • Include the README inside the ZIP file, or upload it separately alongside other files.
    • Repeat the key README content in the Zenodo Description field so it is visible on the record landing page.
    • Provide the README in plain text format (.md or .txt) — avoid .docx.

    5. Select your preview file

    • The preview file is displayed when someone accesses the DOI. By default, it follows alphanumerical order.
    • Change the preview file by checking the Preview checkbox in the file list.
    • If uploading individual files (not a ZIP), set the README as the preview file.

    Preview file selection

    6. Check your data classification

    • If your data is set to Open, make sure you are not accidentally sharing sensitive data.
    • If unsure, check with your data management team before publishing.

    You cannot modify data files after publishing

    Once a record is published, you cannot add, remove, or modify data files. To make changes, you must create a new version of the record. See Zenodo — How to manage versions.

    What next?

    Account set up and ready to go! Continue to Step 2 — Organise your Data to prepare your files before uploading.
