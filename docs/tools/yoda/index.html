    Data Transfer Options, Tips and Solutions¶

    Manual for transfering data with Cyberduck - This guide is part of the A-LIFE GEMs (Guides, Essentials & Manuals) Collection.

    Version 0.2.1, Beta, last modified on 2025-08-07 Irene Martorelli, Brett Olivier

    Cyberduck¶

    When you want to transfer data that has a volume more than 20MB, or more than one data file at once, it is highly recommended to use Cyberduck for accessing Yoda and transfering data from your device. In this document we provide 10 steps to start with Cyberduck.

    Please note that you need to have access to Yoda via the portal in order to transfer data. The following steps are for MacOS users.

    :::success

    ✅ 10 Simple Steps for connecting to Yoda with Cyberduck

    1. Download the VU Software Center Tool
    → Go to: https://munki.mac.vu.nl/installers/

    2. In the VU Software Center Tool, search for Cyberduck and install it in your device.

    3. Sign in to the Yoda Portal → Go to: https://portal.yoda.vu.nl. → Sign in by using your-username@vu.nl and VU password.

    4. Generate a new Data Access Password
    → Go to: https://portal.yoda.vu.nl/user/data_access
    → Click Generate new data access password → For the Label, type: Cyberduck
    → Click Generate data access password

    5. Copy the password
    → Highlight the generated password and press Command + C to copy.

    6. Open Cyberduck and add a new bookmark
    → Click the Bookmarks icon
    → Then click the + button

    7. Choose WebDAV (HTTPS) as connection type → Select WebDAV (HTTPS) protocol from the dropdown list.

    8. Fill in the connection details:
    - Server: data.yoda.vu.nl
    - Username: your-username@vu.nl
    - Password: paste (Command + v) the password you generated in point 4.

    9. Close the bookmark window
    → Click the X to return to the main Cyberduck home window.

    10. Connect to Yoda
    → Your new bookmark (data.yoda.vu.nl - WebDAV (HTTPS)) is visible in the home window. → Click to the Yoda bookmark to connect and access your Yoda folders. → You may need to add your VU password when trying to connect for the first time. Save it for next time.

    :::

    :::warning Please note that the Data Access Password is valid for ==90== days. After that, it expires and you will not be able to login in with Cyberduck. To regain access, simply repeat Steps [4 - 7] to create a new password and update it in your Cyberduck bookmark. :::

    :::info For more information please take a look at the VU RDM manual -Yoda using Cyberduck :::
