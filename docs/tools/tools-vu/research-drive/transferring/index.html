    Transferring Data in Research Drive¶

    Work in progress — page to be reorganised

    This page still needs to be restructured to align with the equivalent Transferring Data page in Yoda. Content and structure will be updated in a future revision.

    Overview

    This is the Transferring Data page, part of Research Drive → VU Tools in the A-LIFE RDM collection.

    This document covers three ways to access and transfer data in your Research Drive project space:

    • Using the Research Drive Web Interface
    • Using the OwnCloud desktop synchronisation client
    • Using Cyberduck to connect to Research Drive
    • Using Rclone with Research Drive

    Supporting materials: GEMs — FAQs
    Authors: Irene Martorelli, Brett Olivier — Last modification: 2026-02-23 — Version: 0.7.3

    1. Using the Research Drive Web Interface¶

    The easiest way to access and view your space is via a web browser. Once you log in (see Getting Started), you can access your Research Drive project space directly from your browser.
    The main home page shows the name of your project.

    A-LIFE domain for Research Drive

    A-LIFE is part of Faculteit der Bètawetenschappen (BETA). When a space in Research Drive is created for you, the prefix BETA_ is added to your project name.

    For example: project "microbial-communities" becomes "BETA_microbial-communities" in Research Drive.

    1a. Create folders and share your data¶

    Creating and sharing folders is intuitive — the interface uses common icons for adding and sharing. The main folder (root) you see belongs to your project. Use the + button to create a new folder or add a file.
    Creating a new folder in the project.
    Specifying a file format.

    Organise before you upload

    Check out BP — RDM — Organising Data to help you structure your project repository with a good naming and folder system.

    1b. How to upload a file using the Web Interface¶

    Drag a file from your device directly into the browser folder, or use the + add icon near the folder name and select the upload option.
    Upload a file via the browser interface.

    2. Using the OwnCloud desktop synchronisation client¶

    The OwnCloud desktop client automatically synchronises data between Research Drive and your laptop. If you have used SURFDrive before, it will feel very familiar.

    1. Download the desktop client from https://owncloud.com/desktop-app/
    2. Once installed, provide the server address for the VU Research Drive instance: https://vu.data.surfsara.nl

    3. Using Cyberduck to connect to Research Drive¶

    Cyberduck is a free desktop client that connects to your Research Drive space via WebDAV, allowing you to upload, download, and manage your files with a simple drag-and-drop interface.

    For a step-by-step guide on how to set up and use Cyberduck with Research Drive, see our manual:

    Connect to Research Drive with Cyberduck

    Verify data integrity with Cyberduck

    Cyberduck supports checksum verification during file transfers. You can enable this in Preferences → Transfers to ensure your files have been transferred correctly and without corruption — especially useful for large datasets.

    4. Using Rclone with Research Drive¶

    Rclone is a command-line tool for syncing and transferring files between your local machine and cloud storage. It is a powerful option for automating large or recurring data transfers to Research Drive via WebDAV.

    Further reading

    SURF — How to use Rclone with Research Drive

    What next?

    Once your data is uploaded, and when your project is complete, it is recommended to move your data to Yoda for long-term archiving. Continue to Step 5 — Archiving and Publishing your Data.
