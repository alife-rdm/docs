    Transferring Data in Yoda¶

    Overview

    This is the Transferring Data page, part of Yoda → Storage Tools in the A-LIFE RDM collection.

    This document covers two ways to transfer data to your Yoda Research Space:

    • Via the Yoda web interface
    • Via Cyberduck

    Supporting materials: Manuals
    Authors: Irene Martorelli, Brett Olivier — Last modification: 2026-08-02 — Version: 0.2.0

    1. Via the Yoda Web Interface¶

    Coming soon

    Documentation for transferring data via the Yoda web interface is under development.

    2. Via Cyberduck¶

    Cyberduck is a free desktop client that connects to your Yoda Research Space via WebDAV, allowing you to upload, download, and manage your files with a simple drag-and-drop interface.

    For a step-by-step guide on how to set up and use Cyberduck with Yoda, see our manual:

    Transfer Data with Cyberduck

    What next?

    Once your data is uploaded, you may want to manage who has access to your Yoda Research Space. Continue to Step 4 — Manage Group Members.
