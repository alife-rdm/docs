    Cyberduck¶

    When you want to transfer data that has a volume more than 20MB, or more than one data file at once, it is highly recommended to use Cyberduck for accessing Yoda and transfering data from your device. In this document we provide 10 steps to start with Cyberduck.

    Please be aware that you need to have access to Yoda via the portal in order to transfer data. If you do not have access to the Yoda portal, please make sure to request storage space [add guide link] or ask permission to the Yoda data project owner to grant you access to the space

    ✅ 10 Simple Steps for connecting to Yoda with Cyberduck¶

    1. Download Cyberduck Tool¶

    • For Windows users, go to https://cyberduck.io/download/ and download Cyberduck.
    • For MacOS users, there are two options: download it directly from https://cyberduck.io/download/ or search Cyberduck in the VU Software Center Tool and install it in your device. If you do not have VU Software Center Tool you can download it from: https://munki.mac.vu.nl/installers/.

    2. Sign in to the Yoda Portal¶

    • Go to: https://portal.yoda.vu.nl
    • Sign in by using your-username@vu.nl and VU password.

    3. Generate a new Data Access Password¶

    • Go to: https://portal.yoda.vu.nl/user/data_access
    • Click Generate new data access password
    • For the Label option, type: Cyberduck
    • Click Generate data access password

    4. Copy the password¶

    • Highlight the generated password and press Command + C to copy.

    5. Open Cyberduck and add a new bookmark¶

    • Click the Bookmarks icon of Cyberduck
    • Then click the + button

    6. Choose WebDAV (HTTPS) as connection type¶

    • Select WebDAV (HTTPS) protocol from the dropdown option list.

    7. Fill in the connection details:¶

    • Server: data.yoda.vu.nl
    • Username: your-username@vu.nl
    • Password: paste (Command + v) the password you generated in point 3.

    8. Close the bookmark window¶

    • Click the X to return to the main Cyberduck home window.

    9. Connect to Yoda¶

    • Your new bookmark (data.yoda.vu.nl - WebDAV (HTTPS)) is visible in the home window.
    • Click to the Yoda bookmark to connect and access your Yoda folders.
    • You may need to add your VU password when trying to connect for the first time. Save it for next time.

    10. Manage your project directory via the Cyberduck interface¶

    • you can drap and drop files and foleds from your laptop directories to your Yoda project repository.
    • a transfer window keeps open until the full transfer is complete
    • the same operation (from Yoda project directory) to your laptop folders for dragging folders can be repeaded

    Warning

    Please note that the Data Access Password is valid for 90 days. After that, it expires and you will not be able to login in with Cyberduck. To regain access, simply repeat Steps [3 - 6] for generating a new password and update it in your Cyberduck bookmark.

    Info

    For more information please take a look at the VU RDM manual - Yoda using Cyberduck
