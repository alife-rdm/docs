    A-LIFE RDM GEMs Overview¶

    Overview

    This is the A-LIFE RDM GEMs section of the A-LIFE RDM collection.

    GEMs — Guides, Essentials, and Manuals — brings together practical resources to support A-LIFE researchers in managing their data throughout the research lifecycle.

    • Guides — best practices for research data management and using tools
    • Essentials — key concepts and reference material for applying FAIR principles
    • Manuals — step-by-step instructions for technical tasks

    Authors: Irene Martorelli, Brett Olivier — Last modification: 2026-06-25 — Version: 0.1.0
