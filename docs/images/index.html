    A-LIFE RDM¶

    Welcome to the Research Data Management documentation for A-LIFE researchers.

    This website contains a collection of support documentation for A-LIFE researchers. Researchers dealing with data can use this documentation for improving their data management skills and explore methods and best practices for using the VU research tools that are used for managing, archiving and publishing data.

    What you will find in this collection:¶

    The Guides, Essentials and Manuals (GEMs)¶

    A collection for research data management, including

    • Guides: Guides are friendly documents that we designed to help you getting started with a specific RDM task or using a tool. The guides provide simple steps and context and include examples to make concepts more understanble and familiar. Examples of guides you will find deal with filling in requests forms for using VU storage tool and preparing a dataset for publication.
    • Essentials: The Essentials are brief documents that highlight key things that are good to be aware before beginning a task. These can be for example list of PIDs, standard file formats, definitions and nomenclatures that help to clarify concepts that are essential for good RDM
    • Manuals: Manuals are practical documents that show you exactly how to perform a task. The manuals can be in a format to provide step to step instructions and checklists, such as step-by-step for transfering data with Cyberduck.

    The Storage Solutions Support Documentation (SSSD)¶

    This section covers the practical support documentation for getting started and provides tips and solutions with storage tools, mostly focusing and highlighing the ones supported by VU and listed in VU storage finder.

    • Yoda: Solution for Storage, Archiving and Publishing
    • Research Drive: Solution for Storage and Sharing
    • OSF: Solution for Storage, Sharing and Publishing
